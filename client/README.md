# 동아리 플랫폼 프론트엔드

Vite + React + TypeScript로 구현된 동아리 관리 플랫폼 프론트엔드입니다.

## 기술 스택

- **React 18** - UI 라이브러리
- **TypeScript** - 타입 안정성
- **Vite** - 빠른 개발 환경
- **React Router** - 라우팅
- **Axios** - HTTP 클라이언트

## 디자인 시스템

- **컬러**: 흰색/검은색 베이스, 파란색(#2563eb) 포인트
- **스타일**: 모던하고 깔끔한 UI

## 프로젝트 구조

```
src/
├── components/      # 공통 컴포넌트 (Navbar, Layout, Loading 등)
├── pages/          # 페이지 컴포넌트
├── contexts/       # React Context (인증)
├── services/       # API 서비스 레이어
├── types/          # TypeScript 타입 정의
└── utils/          # 유틸리티 함수
```

## 주요 페이지

1. **홈 페이지** (`/`) - 메인 랜딩 페이지
2. **로그인/회원가입** (`/login`, `/register`) - 인증 페이지
3. **동아리 목록** (`/clubs`) - 카테고리별 동아리 조회
4. **동아리 상세** (`/clubs/:id`) - 동아리 정보, 게시글, 관리 탭
5. **마이페이지** (`/mypage`) - 내 정보, 신청 현황, 가입한 동아리
6. **관리자 통계** (`/admin/stats`) - 사이트 전체 통계 (관리자 전용)

## 실행 방법

### 1. 의존성 설치

```bash
npm install
```

### 2. 개발 서버 실행

```bash
npm run dev
```

프론트엔드 서버가 `http://localhost:3000`에서 실행됩니다.

### 3. 백엔드 연동

백엔드 서버가 `http://localhost:5000`에서 실행되어야 합니다.
Vite 프록시 설정으로 자동으로 백엔드 API와 연결됩니다.

### 4. 빌드

```bash
npm run build
```

## 주요 기능

### 일반 사용자
- 회원가입 및 로그인
- 동아리 목록 조회 (카테고리별 필터링)
- 동아리 상세 정보 확인
- 동아리 가입 신청
- 마이페이지에서 신청 현황 및 가입한 동아리 확인
- 개인 정보 수정

### 동아리 관리자
- 동아리 정보 수정
- 게시글 작성/수정/삭제
- 가입 신청 승인/거절
- 회원 목록 조회 및 강퇴

### 사이트 관리자
- 전체 통계 대시보드
- 새 동아리 생성
- 카테고리별 동아리 현황 확인

## 환경 변수

필요한 경우 `.env` 파일을 생성하여 환경 변수를 설정할 수 있습니다:

```
VITE_API_URL=http://localhost:5000/api
```

## 개발 가이드

### 새 페이지 추가

1. `src/pages/` 에 페이지 컴포넌트 생성
2. `src/App.tsx` 에 라우트 추가

### 새 API 추가

1. `src/types/index.ts` 에 타입 정의
2. `src/services/api.ts` 에 API 함수 추가

### 스타일링

- 글로벌 스타일: `src/index.css`
- CSS 변수 사용: `var(--color-primary)` 등
- 컴포넌트별 CSS 파일 작성

## 문제 해결

### CORS 에러
백엔드에서 CORS가 허용되어 있는지 확인하거나, Vite 프록시 설정이 올바른지 확인하세요.

### 로그인 상태 유지
JWT 토큰은 `localStorage`에 저장됩니다. 개발자 도구에서 확인 가능합니다.
